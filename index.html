Exploring a shared snapshot

This proof of concept shares the host's saved arena snapshot. It does not yet synchronize live movement, accounts or internet connections.

Visit protocol

1. Host publishes an arena snapshot.
2. Visitor loads the latest snapshot.
3. Visitor can challenge a configured trainer.

A production version should use a server-authoritative multiplayer room and persistent storage.
